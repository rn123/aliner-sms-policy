Program name: A-Liner SMS Status Bridge

Description

A personal SMS-based query interface for the operator's own off-grid RV monitoring system. Sending a keyword from the registered mobile number (e.g. soc, solar, sl, lp, wx, where) returns a single-message status reply. This service is restricted to a single registered operator and is not a public service.

How consent is given (opt-in / Call to Action)

This is a Sole Proprietor program with exactly one recipient: the account holder, who is also the sole sender. There is no public opt-in — no website form, advertisement, point-of-sale, or third-party enrollment — because there is no audience other than the account holder. Consent is given directly by the account holder entering their own mobile phone number into a configuration file on the RV monitoring system they personally own and operate. That act — the owner enrolling their own number on their own equipment — is the opt-in. The system enforces a single-number allowlist, so no other number can be enrolled. Consent can be withdrawn at any time by replying STOP or by removing the number from the configuration; replying START restores service.

Message frequency

Reply-driven. The system sends one reply per inbound query. Expected volume: fewer than 30 messages per day, varying with usage.

Message and data rates

Standard message and data rates may apply per the recipient's mobile carrier plan.

Support

Email ray.nowell@gmail.com for help.

HELP

Replying HELP (or INFO) returns the list of supported keywords and the support email above, along with the message-and-data-rates notice.

STOP

Replying STOP (or STOPALL, UNSUBSCRIBE, CANCEL, END, QUIT) halts all further messages from this number. The receiving system records the opt-out and ignores every subsequent query until the operator replies START to resume. Carrier-level opt-out filtering is also enforced by the mobile carriers and by Twilio independently of this system.

Eligibility

Sole Proprietor campaign — restricted to the registered operator. No third-party recipients.
