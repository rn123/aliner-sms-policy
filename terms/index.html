Program name: A-Liner SMS Status Bridge

Description

An automated SMS application for an off-grid RV monitoring system. When an authorized recipient texts a keyword (e.g. soc, solar, sl, lp, wx, where) to the service number, the application replies with a single-message status. The application originates every reply. The service is restricted to authorized recipients (the owner and authorized household members) and is not a public service.

How consent is given (opt-in / Call to Action)

This is a Sole Proprietor program. There is no public opt-in — no website form, advertisement, point-of-sale, or third-party enrollment. Each recipient consents by having their mobile number registered with the application by the owner; enrollment is limited to the owner and authorized household members. That registration — the owner adding an authorized number to the application's allowlist — is the opt-in. The application enforces the allowlist, so only registered numbers receive messages. Consent can be withdrawn at any time by replying STOP or by removing the number from the configuration; replying START restores service.

Message frequency

Reply-driven. The system sends one reply per inbound query. Expected volume: fewer than 30 messages per day, varying with usage.

Message and data rates

Standard message and data rates may apply per the recipient's mobile carrier plan.

Support

Email ray.nowell@gmail.com for help.

HELP

Replying HELP (or INFO) returns the list of supported keywords and the support email above, along with the message-and-data-rates notice.

STOP

Replying STOP (or STOPALL, UNSUBSCRIBE, CANCEL, END, QUIT) halts all further messages from this number. The receiving system records the opt-out and ignores every subsequent query until the operator replies START to resume. Carrier-level opt-out filtering is also enforced by the mobile carriers and by Twilio independently of this system.

Eligibility

Sole Proprietor campaign — restricted to authorized recipients (the owner and authorized household members). No public or third-party enrollment.
